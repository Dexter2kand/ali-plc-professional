# Ali Sheikholeslamikandelosi — Siemens TIA Portal PLC Programmer

A professional, mobile-responsive single-page portfolio for Siemens PLC programming. The site uses real, user-provided photos and works without any web framework, npm package, external fonts, trackers, analytics, or cookies.

## Preview locally

Double-click `index.html` to open the website in Chrome or Edge. All linked files need to stay together in their current folder structure:

```
ali-plc-professional/
  index.html
  styles.css
  script.js
  assets/
    ali-portrait.webp
    siemens-plc-lab.webp
    favicon.svg
```

## Editing

* Text, project descriptions and email links: `index.html` (Ctrl+F to find a phrase).
* Colors, spacing, and photo layout: `styles.css`.
* Mobile menu and footer date: `script.js`.
* Your photos: `assets/ali-portrait.webp` and `assets/siemens-plc-lab.webp`.

The mailto links currently use your supplied email: `ali.sheikh1363@yahoo.com`.

## Publish with GitHub Pages

1. Create a **Public** GitHub repository for the website.
2. Upload `index.html`, `styles.css`, `script.js` AND the full `assets/` folder to the repository root.
3. Open Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Visit `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/` once deployment finishes.
